# CampusShelf 功能清单（FEATURES）

## 一、前台功能

| 功能 | 说明 | 入口 |
|------|------|------|
| 首页 Hero + 搜索 | 主搜索框、快捷分类入口、热门/最新资源 | `/` |
| 资源列表 | 6 大分类筛选、关键词搜索、价格区间、新旧程度、排序、分页(8/页) | `/resources` |
| 资源详情 | 资源信息、收藏、加入购物车、评论与评分、相关推荐 | `/resources/:id` |
| 资源发布 | 表单发布（教材/笔记/考研/实验报告/电子书/用品） | `/resources/publish`（需登录） |
| 资源编辑/删除 | 卖家或管理员可编辑、下架、删除 | `/resources/:id/edit` |
| 搜索（实时下拉） | 输入防抖 300ms，实时展示匹配结果 | 全局搜索框 |
| 最近浏览 | localStorage 保存最近 10 个资源 | 首页/个人中心 |

## 二、用户中心

| 功能 | 说明 |
|------|------|
| 注册 / 登录 / 登出 | Passport 本地策略 + session |
| 我的发布 | 查看自己发布的资源（含审核状态） |
| 我的收藏 | 收藏 / 取消收藏的资源列表 |
| 我的订单 | 订单状态（待确认/已完成/已取消） |
| 最近浏览 | 最近查看的 10 个资源（localStorage） |
| 购物车 | 增/删/改数量、结算生成订单 |
| 搜索历史 | localStorage 保存最近 8 条，可点击复用/清空 |

## 三、管理后台（`/admin`，需管理员账号）

| 页面 | 功能 |
|------|------|
| Dashboard | 总用户/资源/订单/评论数、热门分类、近 7 天发布趋势 |
| 资源管理 | 查看 pending 资源，通过/拒绝/下架 |
| 用户管理 | 用户列表、发布数、订单数 |
| 订单管理 | 订单列表、修改状态 |
| 评论管理 | 评论列表、删除评论 |
| 数据统计 | 分类占比图、近 7 天趋势、热门排行、成交趋势（Chart.js） |

## 四、性能优化

| 优化 | 位置 |
|------|------|
| 图片懒加载 `loading="lazy"` | 资源卡片 / 详情 |
| 搜索防抖 300ms | `public/js/campusshelf.js` |
| 列表分页 8 条/页 | `routes/resources/resource.js` |
| localStorage 缓存 | 搜索历史 / 最近浏览 / 主题 / 筛选条件 |
| 加载态 | 实时搜索「搜索中…」、列表「加载中…」遮罩 |
| 响应式 | 手机/平板/桌面三档 |

## 五、加分项（可选，不影响基础功能）

- **Redis 缓存**：`utilities/cache.js`，自动降级内存缓存（见 REDIS_OPTIMIZATION.md）
- **Nginx 部署**：反向代理 + gzip + 静态缓存（见 NGINX_DEPLOYMENT.md）
