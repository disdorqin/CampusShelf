## 任务

工作目录 `D:\PracticeWeek\CampusShelf`，分支 `campus-shelf-upgrade`。参考 UI `_reference/gentelella`（仅借鉴）。

## 关键技术决策
- **存储**：原项目用 MongoDB(2.x)+Google Books API，本地无法直接跑。改为 **JSON 文件层** `utilities/jsonStore.js`（DATA_DIR=项目/data），零依赖可运行。MongoDB 仅作可选扩展点。
- **认证**：保留 Passport+session；LocalStrategy 必须用 `usernameField:'email'`（表单字段是 email，否则登录永远失败）。bcrypt-nodejs → bcryptjs。移除 reCAPTCHA。
- **缓存**：`utilities/cache.js` Redis 优先、内存 Map 降级；启动打印 `Redis unavailable, using memory cache`。
- **数据模型**：Resource(6分类 textbook/notes/exam/report/ebook/supplies, status pending/approved/rejected/sold)、Comment、Order。seed: `scripts/seedResources.js`(36资源+6评论)、`scripts/seedUsers.js`(admin@campusshelf.com/admin123, student@campusshelf.com/student123)。

## 重要坑
- **Windows 测试必须用 `NO_PROXY=localhost curl`**：否则 curl 走 127.0.0.1:7890 代理返回 502/错误。`-o /dev/null` 在代理下报 curl error 23，改写到临时文件。
- **端口 3000 易被旧 node 进程占用**：每次改代码后必须 `Stop-Process -Id <pid> -Force`(PowerShell) 彻底杀掉再重启，否则测试打到的还是旧代码（表现为改了 guard 仍 403）。
- **注册路由**：原 `insertNewUser().then()` 是 Promise API，新同步实现会 `TypeError: .then is not a function` 导致进程崩溃。已改为同步回调。
- **curl `--data-urlencode` 在 GBK 终端会把中文按 GBK 编码**，导致评论文本乱码（应用本身 UTF-8 正常，纯测试假象）。
